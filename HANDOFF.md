## Что НЕ сработало
1. Variable-шрифт Onest (как в сборщике) — GDI оси не понимает; брать статические начертания
2. Шрифт только через `PrivateFontCollection` — TextRenderer (GDI) его не видит и подставляет системный; нужен ещё `AddFontMemResourceEx`
3. Google Fonts CSS API с браузерным UA отдаёт woff, порезанные по алфавитам; с UA curl по умолчанию — цельные TTF на каждое начертание
4. TextBox с Onest и `AutoSize` срезает «_» (имя `slide_kite_4` выглядело как `slide kite 4`) — `Box.AutoSize = false`, высота `Font.Height + 6`
5. `SectionLabel` фиксированной ширины 220 в «Слайде» закрывали соседние подписи колонок — ширина по тексту
6. Снимок `PrintWindow` безрамочных окон (`PromptDialog`, `CaptureDialog`) — чёрный; для них `DrawToBitmap`. Диалог сразу после `Show()` снимается недорисованным (белые прямоугольники) — дать 10 × `DoEvents` + 40 мс
7. Пересборка при запущенной программе — `CS2012: Cannot open …MacroKit.exe for writing`
